## Overview
This project is a custom-designed 3D printed dice dispenser capable of reliably dispensing one die at a time. The goal was to design a compact and functional mechanism that prevents jamming while maintaining smooth operation.

The design was created in Fusion 360 and iterated through multiple prototypes to improve reliability and usability.

---

## Features
- Single-die dispensing mechanism  
- Anti-jam internal geometry  
- Compact and portable design  
- Gravity-fed system  
- Spring-assisted release mechanism  
- Fully 3D printable components  

---

## Design Process
